# Project Definition

## 1. Overview

Astronomical Database is a web application designed to
explore and visualize astronomical structures stored in
a relational database.

The application will provide an interactive representation
of the relationships between astronomical structures,
allowing the user to navigate between them and inspect
their physical properties.

The visual representation will be inspired by the spatial
exploration and map systems found in No Man's Sky, while
maintaining a degree of astronomical rigor.

The simulation will not attempt to reproduce the real
universe with exact physical or spatial accuracy.

---

## 2. Purpose

The main purpose of the project is educational.

The project will be used to develop practical experience in:

- Relational database design
- SQL
- Backend development
- API development
- Frontend development
- Data visualization
- Git and version control

---

## 3. Core Concept

The application will represent astronomical structures
and their relationships as an interactive spatial system.

The user should be able to navigate through different
levels of astronomical structures.

For example:

Galaxy
→ Stellar System
→ Star
→ Planet
→ Natural Satellite

The application will retrieve information from the
relational database through the backend API.

---

## 4. Core Features

The initial version should allow the user to:

- Explore galaxies
- Explore planetary systems
- Explore stars
- Explore planets
- Explore natural satellites
- Explore minor bodies
- View the physical properties of astronomical objects
- Navigate between related structures
- Search for astronomical objects
- Filter objects by relevant properties

---

## 5. Visualization

The application will provide a spatial visualization
of astronomical structures.

The visualization is intended to communicate:

- Relative spatial relationships
- Hierarchical relationships
- Scale
- Distance
- Navigation between structures

The visualization does not attempt to reproduce the
real spatial distribution of the universe exactly.

Astronomical data will be used where appropriate,
but visual scales may be modified to make the system
usable and understandable.

---

## 6. Scope

The first version will focus on a limited set of
astronomical structures and interactions.

The following features are outside the initial scope:

- Multiplayer
- User accounts
- Authentication
- Real-time astronomical data
- Full physical simulation
- Gravitational simulation
- Procedural generation of an entire universe
- Exact reproduction of the observable universe

These features may be considered in the future but are
not required for the initial project.
