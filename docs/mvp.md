## MVP

The MVP will provide a basic interactive web application
for exploring astronomical structures stored in the
relational database.

The user will be able to:

1. View a visual representation of astronomical structures.
2. Select a galaxy.
3. View information about the selected galaxy.
4. Navigate to planetary systems associated with the galaxy.
5. Select a planetary system.
6. View the stars and planets associated with the system.
7. Select an astronomical object.
8. View its stored physical properties.

The MVP will use a simplified visual representation
rather than attempting to reproduce the actual spatial
distribution of the universe.


## Out of Scope for MVP

The MVP will not include:

- Realistic gravitational simulation.
- Physically accurate 3D spatial representation.
- Procedural generation of the universe.
- Millions of astronomical objects.
- User accounts.
- Multiplayer functionality.
- Real-time astronomical data.
- Advanced search.
- Advanced filtering.
- Object comparison.
