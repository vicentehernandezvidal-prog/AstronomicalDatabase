# Astronomical Database

## Descripción

Aplicación web interactiva para explorar y visualizar
estructuras astronómicas almacenadas en una base de datos
relacional.

El proyecto busca integrar una base de datos, un backend
y un frontend para representar las relaciones entre
distintas estructuras astronómicas.

## Objetivo

El objetivo principal del proyecto es desarrollar
experiencia práctica en:

- Bases de datos relacionales
- SQL
- Desarrollo backend
- Desarrollo frontend
- APIs
- Visualización de datos
